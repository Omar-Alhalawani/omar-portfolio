01 // RTL + VERIFICATION

Synchronous FIFO

A parameterized single-clock FIFO in SystemVerilog. Storage is a fixed memory array; write and read pointers track the active locations, while a count register drives the empty and full flags.

Interface and behavior

Writes occur when wr_valid and wr_ready are both asserted. Reads use the matching rd_valid/rd_ready handshake. The output is registered, and simultaneous reads and writes are accounted for without changing occupancy.

Verification approach

The supplied testbench uses a queue as the reference model. It checks read data one cycle after an accepted read, then exercises reset, fill-to-full, drain-to-empty, pointer wrap, and simultaneous traffic. It is set up to produce a VCD for waveform inspection with Icarus Verilog.

02 // FPGA RTL

FPGA Arithmetic System

A Verilog design for a ZedBoard that captures two 8-bit operands from the DIP switches, performs add or subtract on a button edge, and shows the low eight result bits on the board LEDs.

Control path

Each pushbutton input passes through a two-flip-flop synchronizer and rising-edge detector. BTNL captures A, BTNR captures B, BTNU selects addition, BTND selects subtraction, and BTNC clears the stored operands and mode.

Implementation notes

The top level targets the ZedBoard Zynq XC7Z020 and assigns the design clock to the 100 MHz board clock. The arithmetic is formed in a 9-bit intermediate result before the low eight bits drive the LEDs.

03 // INSTRUMENTATION

EMG Signal Acquisition & Processing

An acquisition-to-analysis workflow for EMG data: a MyoWare sensor feeds a microcontroller, the samples are streamed over serial, and Python handles plotting and processing.

Signal path

The project joins the hardware and software sides of a measurement loop. The microcontroller is responsible for capture and transport; the Python side receives the stream and makes the signal inspectable.

Processing focus

The public project description identifies noise reduction and visualization as the analysis work. This case study deliberately keeps the processing description at that level: no filter order, sampling rate, or physiological claim is presented without published source support.
